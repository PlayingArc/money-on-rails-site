# Money on Rails — public site

Three-page public static site (Landing, Terms of Service, Privacy Policy) for
[Money on Rails](https://github.com/PlayingArc/money-on-rails), served on GitHub
Pages. Deliberately separate from the app's own (private) repository — see that
repo's [`.scratch/money-on-rails-build-effort/issues/01-stand-up-repo-and-static-site.md`](https://github.com/PlayingArc/money-on-rails/blob/main/.scratch/money-on-rails-v1-build-effort/issues/01-stand-up-repo-and-static-site.md)
for why.

Legal content is drafted, not yet lawyer-reviewed — see the `DRAFT` comment in
`terms.html` and `privacy.html`.

No build step: plain HTML/CSS, deployed as-is via GitHub Pages from `main`.
